# OpenSDR

> Production-ready, 100% open-source alternative to Clay and autonomous AI SDRs.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python: 3.10+](https://img.shields.io/badge/Python-3.10%2B-brightgreen.svg)](https://python.org)

OpenSDR replicates the core feature set of high-ticket outbound sales platforms (like Clay and 11x) without per-credit fees or vendor lock-in.

---

## Key Features

1. **Waterfall Lead Enrichment Engine:** Cascades through free web scrapers, company registries, email permutation generators, and live DNS/MX validators to discover and verify decision-maker contacts.
2. **Autonomous Web Research Agent:** Analyzes prospective company domains, career pages, and press mentions to extract value propositions, pain points, and buying triggers.
3. **AI Personalization Copywriter:** Automatically drafts hyper-tailored cold outreach emails (Pain-Agitate-Solution, Value-First, Quick Question) with custom icebreakers.
4. **Campaign Sequencing and Inboxing:** Schedules multi-step drip cadences, handles inbox rotation, and tracks outreach stages.
5. **REST API & CLI:** Simple CLI commands and FastAPI REST endpoints for integrating directly into your stack.

---

## Development Roadmap & Phases

- **Phase 1:** Core Data Models & Waterfall Enrichment Engine
- **Phase 2:** Autonomous Web Research Agent
